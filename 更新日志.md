# 更新日志 / Changelog

本文件是 TerraFirmaEarth 的**完整**版本更新记录，仅作项目内记录、**不随包发布**。`mods.toml` 的介绍页不放日志，只保留功能总览（日志里仍在生效的改动已并入功能列表），逐条细节以本文件为准。
This file is the **complete** release history of TerraFirmaEarth. It is a project-internal record and is **not shipped** with the release. The mod description deliberately carries no changelog section, only a feature overview; the per-version details below are the source of truth.

规则：新增版本时**先写中文，再写英文**（同一版本号，条目一一对应）。
Rule: when adding a release, write the Chinese entry first and the English entry second (same version number, one-to-one items).

## 中文

### 2.2.0 更新概括

- 大幅度修改了绳锚系统，使其更真实，前中期更有价值。
- 新增了溪流群系地下部分。

### 2.1.0 更新概括

- 移植最新版 TFC 的地形、气候、生物、植物与相关内容。
- 移植了土壤肥力设定。
- 优化了全部地形的生成减少了地形破坏类概率，现在全部地形整体更干净平坦统一。
- 新增绳索及相关交互功能。
- 增加作物全状态 Jade 显示，新增作物健康机制。
- 优化勘探系统，调整果树气候条件。
- 优化并补充 TFE 帕秋莉手册，整理各项功能的目录与说明。
- 具体机制与参数均可查阅帕秋莉手册。

### 2.0.1 更新概括

- 新增全新的河流群系溪流。
- 减少河流群系高岸上的砂砾。
- 修复死亡不掉落时，手持锤子和凿子对准石块死亡可能导致的崩溃。
- 重做勘探系统，具体机制请查看帕秋莉手册。
- 重做船的浮力，现在船可以沿水流上升。
- 重做全部作物的气候条件，具体数据请查看帕秋莉手册。
- 重做全局温度算法,见帕秋莉。
- 优化 TFE 的帕秋莉手册。
- 修复其他若干问题。

### 1.1.3 更新概括

- 海洋的淤泥海床替换为更浅的砂砾海床。
- 将注册进tfc的物品带上tfe的标记，jei上搜索@tfe也能显示本mod的全部物品了。

### 1.1.2 更新概括

- 修复沿海沙滩等地形生成异常。
- 优化火山的地势选择。
- 优化木薯营养值。
- 灌木和果树的生长条件对齐 1.21，并额外将温度需求改为当前温度。
- 气候不适宜不再导致灌木和果树树苗死亡，而是停止生长。
- TFCModernLife群峦现代化生活兼容：温室范围是以当前温度为基准进行控温。且建议使用此模组作为本模组温室、地窖和电力厨房相关拓展，勿重复启用.

### 1.1.1 更新概括

- 修复香蕉树自然生成时底部可能插进土里的问题。
- 修复凝灰岩砂砾陶盘阶段模型显示异常。
- 修复炉灶锅液面、产物与锅内物品客户端显示位置异常。
- 增强小萝卜，栽培成熟收获产量翻倍。
- 调整平均湿度提示，参考值不再显示太高 / 太低警告。

### 1.1.0 更新概括

- 高阶地地形优化。
- 修复山区河道入海口概率被堵的问题。
- 平滑山体山峰生成。
- 森林生成更匹配地形。
- 高岭土刷新在腐殖土内时增加一层高岭土草方块覆盖。

### 1.0.2 更新概括

- 增加了自由放置木堆。
- 修复了浮空树，浮空腐殖土。去掉了死火山的地势。补全了水生成逻辑水-死火山水坑生成较少的问题.

### 1.0.1 更新概括

- 新增 TFC 结构与森林树池兼容修复，改善 TFC Structures / AFC 等联动下的树配置、森林层与腐殖层表现。
- 补齐和修复一批移植植物贴图、模型与地物资源。
- 新增山区地势设计，修复水下浮空石锥，并开放相关地势配置。
- 补充仙人掌木材循环、仙人掌整株砍伐掉落、炉灶 / 炉灶锅移植与红木等地物兼容。
- 新增地下河与普通河流切割过渡层，减少洞口和河谷交界处的硬切线。
- 修复旧存档或外部数据包导致的群系兼容崩溃，并修正作物湿度范围与耕地平均湿度显示。
- 重写苜蓿和油菜用途：苜蓿可作为更多常见动物饲料，油菜新增油菜籽榨油路线。

## English

### 2.2.0 Update Summary

- Substantially reworked the rope anchor system: more realistic, and far more valuable in the early and mid game.
- Added the underground sections of stream biomes.

### 2.1.0 Update Summary

- Ported the latest TFC terrain, climate, fauna, flora, and related content.
- Ported the soil fertility settings.
- Optimized terrain generation across all terrain types to reduce terrain-damaging probabilities, making the overall terrain cleaner, flatter, and more consistent.
- Added ropes and related interactions.
- Added full crop-state information to Jade and introduced crop health.
- Improved the prospecting system and adjusted fruit-tree climate conditions.
- Improved and expanded the TFE Patchouli field guide with organized entries for each feature.
- See the Patchouli field guide for detailed mechanics and parameters.

### 2.0.1 Update Summary

- Added brand-new streams to river biomes.
- Reduced gravel on high river-biome banks.
- Fixed a crash that could occur when dying with no item drops while holding a hammer and chisel and aiming at a stone block.
- Reworked the prospecting system; see the Patchouli field guide for details.
- Reworked boat buoyancy, allowing boats to travel upward with flowing water.
- Reworked climate requirements for all crops; see the Patchouli field guide for details.
- Reworked the global temperature algorithm; see the Patchouli field guide for details.
- Improved the TFE Patchouli field guide.
- Fixed several other issues.

### 1.1.3 Update Summary

- Replaced ocean mud seabeds with a thinner gravel surface layer.
- Marked this mod's items registered under the tfc namespace as TFE-provided, so searching @tfe in JEI now shows all items from this mod.

### 1.1.2 Update Summary

- Fixed terrain generation issues around coastal beaches and related shore terrain.
- Optimize the terrain selection for volcanoes
- Improved cassava nutrition values.
- Aligned berry bush and fruit tree growth conditions with TFC 1.21, and changed their temperature checks to use current temperature.
- Unsuitable climate no longer kills berry bushes or fruit tree saplings; affected plants now stop growing instead.
- TFCModernLife (群峦现代化生活) compatibility: greenhouse control is based on current temperature. It is recommended as the greenhouse, cellar and electric kitchen expansion for this mod; do not enable duplicate greenhouse expansions at the same time.

### 1.1.1 Update Summary

- Fixed naturally generated banana plants sometimes sinking into terrain.
- Fixed tuff gravel pan stage model rendering.
- Fixed client-side rendering offsets for stove pot fluid, outputs and contents.
- Improved radishes: cultivated mature harvest yield is doubled.
- Adjusted average hydration display: reference values no longer show too high / too low warnings.

### 1.1.0 Update Summary

- Optimized terrace terrain.
- Fixed mountain river mouths sometimes being blocked at the sea.
- Smoothed mountain peak generation.
- Made forest generation fit terrain more closely.
- Added a kaolin clay grass cover layer when kaolin generates inside humus.

### 1.0.2 Update Summary

- Added freely placeable log piles.
- Fixed the floating trees and floating humus soil. Removed the terrain of the extinct volcano. Completed the logic for generating water - reducing the issue of fewer water pits being generated.

### 1.0.1 Update Summary

- Added TFC Structures and forest-tree compatibility fixes, improving tree entries, forest layers and humus behavior with TFC Structures / AFC setups.
- Fixed and completed a batch of ported plant textures, models and feature resources.
- Added the mountain terrain uplift system, fixed underwater floating cave spikes, and exposed the related terrain config.
- Added the cactus wood loop, whole-saguaro harvest drops, stove / stove pot port, redwood and related feature compatibility.
- Added a transition layer between normal rivers and underground rivers to reduce hard cuts near cave mouths and river valleys.
- Fixed compatibility crashes from old saves or external datapacks, and corrected crop hydration ranges plus average farmland hydration display.
- Reworked alfalfa and canola usage: alfalfa now feeds more common animals, and canola uses a dedicated oilseed route for oil pressing.
